# SS · سیستم مطالعه — نسخه ۵ (کامل)

اپ شخصی، فارسی (راست‌به‌چپ) و **کاملاً آفلاین** برای مدیریت تست‌ها، مرور فاصله‌دار، آزمون‌ها و برنامه هفتگی.
هیچ داده‌ای از دستگاه شما خارج نمی‌شود. هیچ هوش مصنوعی آنلاین یا سرویس خارجی استفاده نمی‌شود.

## ۱. پیش‌نیاز
| مورد | توضیح |
|---|---|
| Node.js نسخه ۱۸ یا بالاتر (پیشنهاد: ۲۰ LTS) | از nodejs.org نصب کنید. بعد از نصب در ترمینال بزنید `node -v` |
| مرورگر | Chrome، Edge یا Firefox جدید (برای نصب به‌صورت اپ: Chrome/Edge) |
| اینترنت | **فقط یک بار** برای `npm install`. بعد از آن همه‌چیز آفلاین است. |

## ۲. راه‌اندازی (اولین بار)
```bash
# ۱) فایل زیپ را باز کنید و وارد پوشه شوید
cd ss-study-system

# ۲) نصب وابستگی‌ها (یک بار، نیاز به اینترنت)
npm install

# ۳) اجرا
npm run dev
```
سپس در مرورگر باز کنید: **http://localhost:5173**
(چون با `--host` اجرا می‌شود، روی گوشیِ همان شبکه Wi-Fi هم با آدرس IP کامپیوتر باز می‌شود؛ ترمینال آدرس را نشان می‌دهد.)

> اگر `npm install` در ایران کند بود، از mirror استفاده کنید:
> `npm config set registry https://registry.npmmirror.com` و دوباره `npm install`.

## ۳. ساخت نسخه نهایی (Build) و اجرای آفلاین دائمی
```bash
npm run build      # خروجی در پوشه dist
npm run preview    # اجرا روی http://localhost:4173
```
- پوشه `dist` را می‌توانید روی هر سرور ساده (حتی فلش/شبکه مدرسه) بگذارید.
- با اولین باز شدن روی http، Service Worker فایل‌ها را ذخیره می‌کند و اپ **بدون اینترنت** هم باز می‌شود.
- **نصب به‌عنوان اپ (PWA):** در Chrome/Edge روی آیکون «نصب» در نوار آدرس بزنید. روی اندروید: منو ← «افزودن به صفحه اصلی».

## ۵. شروع کار
1. اولین بار برنامه خالی است. برای دیدن همه امکانات: **بیشتر ← تنظیمات و پشتیبان ← دیدن داده نمونه**. داده نمونه جدا از داده‌های واقعی نگه داشته می‌شود؛ با «برگشت به داده‌های خودم» خارج شوید.
2. **کتاب‌ها:** برای هر مبحث، بازه شماره تست‌ها (از ... تا ...) و کلید را وارد کنید. این مهم‌ترین قدم است؛ ثبت تست از روی همین بازه‌ها مبحث را پیدا می‌کند.
3. **مباحث خوانده‌شده:** مشخص کنید هر مبحث «تدریس شد» یا «خودم خواندم».
4. **ورود سابقه:** تست‌های قدیمی دفترتان را (تعداد درست/غلط/نزده) وارد کنید.
5. **آزمون‌ها ← + آزمون قدیمی:** آزمون‌هایی که قبلاً زده‌اید را با همه دفعه‌ها ثبت کنید.
6. **آزمون‌ها ← + آزمون جدید:** آزمون بعدی را با بودجه‌بندی ثبت کنید.
7. **برنامه ← پیشنهاد بده** و بعد **تأیید**.

## ۶. راهنمای بخش‌ها

### ثبت تست (جدید در نسخه ۵)
- **فقط شماره‌ها:** درس و کتاب را انتخاب کنید و بنویسید «از تست ۱۲۰ تا ۱۴۵». سیستم خودش تشخیص می‌دهد این تست‌ها در کدام مبحث‌ها هستند و جلسه را بین آن‌ها تقسیم می‌کند. پیش‌نمایش تقسیم را قبل از افزودن می‌بینید.
- **اگر شماره‌ای مبحث نداشته باشد:** خطا نشان داده می‌شود و یک **پنجره کوچک دستیار** توضیح می‌دهد چه کنید: همان‌جا مبحث را انتخاب کنید («وصل کن و ادامه بده»؛ اگر مبحث بازه ندارد بازه جدید ثبت می‌شود و اگر بازه مجاور دارد گسترش می‌یابد) یا به «کتاب‌ها» بروید.
- **از برنامه امروز:** کارهای تستیِ تأییدشده در برنامه بالای صفحه می‌آیند. با یک کلیک، مبحث و اولین تست‌های نزده آن باز می‌شود و مستقیم به پاسخ‌برگ می‌روید. بعد از ثبت، آن کار در برنامه «انجام شد» می‌خورد.
- **مرحله توضیحات (بعد از زمان حدودی):** نوع تست‌ها: «جدید، طبق برنامه» / «جدید، خارج از برنامه» / «تکراری (قبلاً زده بودم)» + توضیح آزاد. تست‌های تکراری در تحلیل وزن کمتر می‌گیرند.
- پاسخ‌برگ: کلید ۱ تا ۴، فاصله یا ۰ = نزده، ؟ = حدسی، یا رشته پاسخ را یکجا paste کنید.

### مرور (قوی‌تر در نسخه ۵)
- زمان‌بندی FSRS؛ هر غلط و نزده خودکار کارت مرور می‌شود. اول فقط شماره تست نشان داده می‌شود («اول حل کن»)، بعد کلید.
- **حالت‌ها:** مرور امروز (با سقف روزانه و سقف کارت جدید از تنظیمات) · مخلوط (دو کارت پشت سر هم از یک فصل نمی‌آید) · قبل از آزمون (فقط مباحث آزمون پیش‌رو) · سرسخت‌ها (کارت‌هایی که ۴ بار یا بیشتر فراموش شده‌اند).
- **فیلتر:** بر اساس درس، فقط غلط‌ها یا فقط نزده‌ها.
- روی هر دکمه امتیاز، فاصله مرور بعدی نوشته شده (مثلاً «بعدی: ۳ روز»). احتمال یادآوری فعلی هم نمایش داده می‌شود.
- **نکته روی کارت**، «فردا»، «کنار بگذار» و **برگرداندن آخرین امتیاز**.
- آمار: درصد یادآوری ۳۰ روز، روزهای پیاپی، سررسید ۷ روز آینده، مبحث‌های پرخطا با دکمه «به برنامه».

### آزمون‌ها (سه نوع)
| نوع | کاربرد |
|---|---|
| **قدیمی** | برای سوابق و بهتر کردن برنامه. هر بار که آزمون را زده‌اید با «یک بار دیگر زدم» ثبت کنید. **همه درصدها ذخیره می‌شوند، اما تحلیل فقط از آخرین نتیجه استفاده می‌کند.** ورود به دو روش: تعداد درست/غلط/نزده، یا رشته جواب‌ها + کلید. |
| **پیش‌رو (جدید)** | آزمونی که قرار است بدهید: بودجه‌بندی (تعداد سؤال و مباحث هر درس) ← شاخص آمادگی، بازه درصد هر درس، مباحث نخوانده/نزده/ضعیف/در حال فراموشی ← «ساخت پیش‌نویس برنامه آمادگی». در «برنامه» به‌عنوان آزمون پیش‌رو نمایش داده می‌شود و پیشنهادهای هفتگی را تغییر می‌دهد. |
| **برگزارشده** | وقتی تاریخ آزمون جدید گذشت، فرم ثبت نتیجه باز می‌شود. پیش‌بینی با نتیجه واقعی مقایسه می‌شود و آزمون به این دسته می‌رود. |

### برنامه (جدید در نسخه ۵)
- **درصد فشار:** فشار هر روز = (دقیقه‌ها × شدت کار) ÷ سقف عادی آن روز. ۱۰۰٪ یعنی یک روز کامل. شدت: درسنامه ۱٫۲۵، تست نزده ۱٫۱، تست هدفمند ۱، آزمون شبیه‌ساز ۱٫۳، مرور ۰٫۷، تحلیل خطا ۰٫۶. **فشار هفته** هم جمع کل است.
- **برنامه کوچک:** نمودار ۷ روزه با تعداد کارها و فشار هر روز (سبز = سبک، زرد = پرفشار، قرمز = بیش از توان).
- **دستیار برنامه:** اول یک توضیح کلی می‌دهد. با «توضیح جزئی‌تر» یا کلیک روی هر روز، جزئیات آن روز را می‌گوید. بعد پیشنهاد جابه‌جایی می‌دهد که با «اعمال» انجام می‌شود (روزهای سنگین، روز قبل از آزمون، کارهای پشت‌سرهم از یک درس).
- **انتقال و جابه‌جایی:** کار را بکشید و روی روز دیگر رها کنید، یا از «انتقال…» استفاده کنید (فشار روز مقصد کنار نام روز نوشته شده). با ▲▼ ترتیب کارهای یک روز را عوض کنید. کارهای مربوط به یک آزمون به بعد از تاریخ آن آزمون منتقل نمی‌شوند.
- **سبک‌تر گرفتن یک روز:** در هر روز گزینه عادی / کمی سبک (۷۵٪) / سبک (۵۰٪) / خیلی سبک (۲۵٪) را انتخاب کنید، یا از بخش «کدام روز را راحت‌تر بگیرم؟» در دستیار استفاده کنید. کارهای کم‌اولویت آن روز به روزهای خلوت‌تر می‌روند و پیشنهادهای بعدی هم این سقف را رعایت می‌کنند.
- پیشنهادها همیشه **پیش‌نویس** هستند (کادر خط‌چین) تا وقتی تأیید کنید. تیک زدن کارهای تأییدشده سکه پاداش می‌دهد.

### بقیه
داشبورد (شمارش معکوس آزمون، کارهای امروز) · تحلیل · کتاب‌ها · پاداش (دفتر ثابت امتیاز، فروشگاه) · دستیار (ثبت سریع، وضعیت، مشاور) · نیمرخ من · تنظیمات و پشتیبان.

## ۷. داده‌ها و پشتیبان
- همه داده‌ها در حافظه مرورگر (localStorage) همان دستگاه هستند. پاک کردن داده‌های مرورگر = پاک شدن داده‌ها.
- **هر هفته پشتیبان بگیرید:** تنظیمات و پشتیبان ← «ساخت فایل پشتیبان» (فایل `.ssbak`). بازگردانی از همان‌جا.
- «ذخیره ماندگار مرورگر» را در تنظیمات فعال کنید تا مرورگر داده را خودکار پاک نکند (مهم در iPhone/Safari).
- انتقال به دستگاه دیگر: فایل پشتیبان را آنجا بازگردانی کنید.
- ارتقا از نسخه‌های قبل خودکار است (مهاجرت v3 → v4 → v5) و هیچ داده‌ای حذف نمی‌شود.
