# معرفی کوتاه Study System (SS)

Study System یک پلتفرم فارسی و راست‌به‌چپ برای مدیریت یادگیری، آمادگی امتحان و کنکور، تحلیل تست و برنامه‌ریزی تطبیقی است.

هسته برنامه از زنجیره «نقشه دانش، کتاب و مبحث، تمرین، پاسخ، تحلیل خطا، مرور فاصله‌دار، آزمون و برنامه‌ریزی» تشکیل می‌شود. محصول ابتدا به‌صورت local-first و بدون وابستگی اجباری به اینترنت یا API تجاری هوش مصنوعی طراحی شده و در آینده می‌تواند به School Hub، کلاس‌های مشترک، همگام‌سازی، دستیار محلی، ربات تلگرام و استقرار وب گسترش پیدا کند.

هوشمندی برنامه به‌صورت مرحله‌ای ساخته می‌شود: ابتدا مدل‌های شفاف و قابل توضیح مانند BKT، IRT و PFA؛ سپس شبکه مهارت و مدل‌های عصبی کوچک مانند GRU یا GNN، فقط پس از جمع‌آوری داده کافی و اعتبارسنجی زمانی. برنامه از MBTI، سبک‌های یادگیری و تشخیص روان‌شناختی غیرمعتبر برای محدودکردن آموزش استفاده نمی‌کند.

این بسته شامل دو سند اصلی است:

- گزارش بررسی نسخه‌های قبلی و پیشنهادهای اصلاحی.
- نقشه جامع مهندسی محصول، یادگیری، هوش محلی، مدرسه، آفلاین، تلگرام، محتوا و امنیت.

این اسناد برای تحویل به تیم یا هوش مصنوعی دیگر جهت طراحی و کدنویسی آماده شده‌اند؛ قبل از کدنویسی باید تصمیم‌های باز، مجوز محتوا، سیاست داده و معیارهای پذیرش نهایی شوند.
